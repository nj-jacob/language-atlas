# Language Atlas

Free study site for the Ontario Language curriculum (2023), Grades 1 to 8, for one child with learning challenges, used with a parent or tutor. Part of **Atlas**, one site for Ontario Math and Language (the [math-atlas](https://github.com/nj-jacob/math-atlas) repository publishes it).

- One idea on screen at a time: Watch me, Together, On your own.
- Practice that adjusts its level, a chapter quiz, and a check-up that makes a plan.
- Grown-up view shows coaching notes and common mistakes for the parent or tutor.

Plain web pages with no build step. Live at https://ontario-math-atlas.web.app/language/ once publishing is set up (see `SETUP.md`).
